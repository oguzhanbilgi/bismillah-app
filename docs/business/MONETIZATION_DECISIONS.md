# Monetization Decisions

Canonical monetization decisions for Bismillah. All revenue figures are **targets,
not guarantees**. Prices are initial values and are testable against store and user
data. Taxes, refunds, accounting, and other costs are evaluated separately.

## Goal

- Monthly advertising budget: **3,000–4,000 TL**
- Target operating net after store commission and advertising: **5,000–10,000 TL/month**
- This is a target, not a guarantee.

## Android pricing (initial, testable)

```text
Bismillah+ monthly: 79.99 TL
Bismillah+ yearly:  initial test around 649.99 TL
Destekçi monthly:   initial test around 199.99 TL
Destekçi yearly:    initial test around 1,499.99 TL
```

## iOS pricing (initial, testable)

```text
Bismillah+ monthly: 129.99 TL
Bismillah+ yearly:  initial test around 999.99 TL
Destekçi monthly:   initial test around 249.99 TL
Destekçi yearly:    initial test around 1,999.99 TL
```

## Free tier

- Prayer times and core tracking
- Quran reading
- Core recitation audio
- Bookmarks and resume
- Basic Today plan
- Learn core library
- Basic Assistant
- Privacy / reset controls
- No ads in sacred content

## Bismillah+

- Advanced personal programs
- Rich reports
- Advanced statistics
- Khatm plans
- Additional personalization
- Themes / widgets
- Larger Assistant capacity where safe
- Optional future backup / sync

## Destekçi

- All Bismillah+ features
- Optional supporter badge
- Exclusive themes / icons
- Early access
- Beta priority
- Roadmap surveys
- **No stronger religious answers**
- **No spiritual-status claim** (support tier, not spiritual superiority)

## Ethical guardrails

- Core worship tools remain free.
- No ads in Quran, Prayer, or sacred Learn content.
- No guilt, fear, or religious-superiority framing in paywalls.
- Paying users do not receive more authoritative religious answers.
- No fake discounts or countdown timers.

- **TASK 115** — Google Play soft launch and first possible revenue

- **TASK 122** — 90-day commercial validation (5,000–10,000 TL target evaluation)
- **TASK 130** — iOS launch (Android + iOS commercial release complete)
