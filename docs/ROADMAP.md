# Roadmap

This roadmap is directional. **No dates, revenue, or delivery promises are made.**
Items may change based on real user feedback and ongoing scholarly review.

## Completed (in this alpha)

- **Today** — read-only daily overview.
- **Prayer** — offline prayer-time engine, local reminders, daily log, 7-day history.
- **Quran** — Tanzil Arabic reader, bundled Turkish translation, search, bookmarks,
  MP3Quran streaming, Android background/lock-screen audio.
- **Learn core** — source-grounded knowledge base with a publication gate
  (30 published / 2 pending).
- **Profile** — personalization, content-source links, privacy/data controls.
- **Source-grounded Assistant** — deterministic, local retrieval over published Learn
  content.
- **Android background audio** — verified on a real Android device.
- **tr / en / ar** localization and RTL.
- **Public alpha repository preparation** — licenses, notices, docs, CI.

## Next (unordered, no commitments)

- Alpha stabilization and bug fixing.
- Incorporating real user feedback.
- A broader, reviewed Learn corpus.
- A verified official-answer / fatwa index (only from verified official sources).
- iOS physical-device validation (including background audio).
- Short adhan notification options.
- Optional cloud sync.
- Google Play Store preparation.
- An ethical premium model.
